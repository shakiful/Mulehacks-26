# UCM mule asset

`ucm-mule.png` is the unmodified mule mark downloaded from the University of Central Missouri branding site.

- Source asset: https://www.ucmo.edu/offices/integrated-marketing-and-communications/internal-resources/fac-staff/ucm-branding/ucm-logos/images/mule-rt-b.png
- Branding reference: https://www.ucmo.edu/offices/integrated-marketing-and-communications/internal-resources/fac-staff/ucm-branding/ucm-logos/

The asset is bundled locally so the prototype does not depend on a third-party image request at runtime. It is displayed with its original colors and proportions.

Navigation uses UCM Red (`#cf202e`), as published in the university's color guide: https://www.ucmo.edu/offices/integrated-marketing-and-communications/internal-resources/fac-staff/ucm-branding/ucm-colors/index.php
